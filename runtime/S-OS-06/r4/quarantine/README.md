## Why one copy here is deliberately NOT tracked

`framework-purity-guard` refused to commit it with `promote_relic=1`, because the file carries a live
legacy-slug-prefixed ledger identifier, which this README deliberately does not quote. The guard is right. Committing a quarantine copy full of legacy
tokens would inject brand-new occurrences into exactly the population this round is driving to zero, and

So the copy stays on disk for inspection and out of the tree. Nothing was bypassed.
