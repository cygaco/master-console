# Acme — Brief

## 01 — Problem
Field techs lose photos across jobs.

## 02 — Solution
Acme captures + tags job photos in one tap, local-first.

## 04 — Vision
The system of record for job-site documentation.

## 09 — MVP
Capture, auto-tag, list, share.

## Tech Stack
- Framework: Next.js
- Database: Supabase
- Authentication: Clerk
- Payments: Stripe
- Hosting: Vercel
- Analytics: PostHog
