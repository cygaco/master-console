# CONVERSION_HIERARCHY — Claude Deep Research Report (3-round WebSearch+WebFetch)

**Engine:** Claude (Opus) iterative search — 3 rounds. Date: 2026-06-01.

## Executive Summary
A converting page has one job; conversion hierarchy is visual hierarchy aimed at that job: hook (above-the-fold benefit value-prop) → proof → one dominant, repeated CTA, with a low attention ratio (links÷goals → ~1:1 on campaign landers) and no competing focal points. The fold still matters as the first-impression/engagement gate (~57% of viewing time above it per NN/g) but "above = promise, below = proof" — users scroll when the top earns it. The dominant CTA is built via Von Restorff isolation (sole accent color + whitespace), emphasis contrast, size/weight, and serial-position placement (strongest value first, strongest close last).

## Phase 1: Landscape
- **One page, one goal; attention ratio = links ÷ conversion goals; 1:1 ideal** for campaign landers (Unbounce/Oli Gardner). Every extra link is an exit. [HIGH] — unbounce attention-ratio
- **Above the fold:** NN/g finds ~57% of viewing time above the fold, ~43% below; modern model "above = promise, below = proof"; users will scroll if engaged. [HIGH] — cxl above-the-fold; NN/g
- Canonical structure: value-prop headline + subhead + primary CTA + proof anchor in first viewport; proof/objection-handling below; repeated CTA. [HIGH] — cxl landing-page anatomy

## Phase 2: Mechanics
- **Von Restorff / isolation effect:** the differing element is noticed & remembered → make the CTA the sole element in the accent color, isolated by whitespace; high-contrast color for the CTA. [HIGH] — lawsofux Von Restorff; AttentionInsight
- **Serial position (primacy/recency):** strongest value first, strongest close + CTA last; weakest material in the middle. [HIGH] — lawsofux serial-position
- **Action hierarchy:** one filled dominant primary; secondary actions ghost/outline/link, visually subordinate; two equal solid buttons = no dominant CTA. [HIGH]
- **Scanning:** F-pattern (text-dense) / Z-pattern (sparse hero); place headline + CTA on the scan path; left-align body. [HIGH] — NN/g
- "Every element installs a belief or removes an objection" — sections that do neither are filler. [HIGH] — cxl

## Phase 3: Failure Modes
Multiple co-equal CTAs; vague/category headline (no benefit); buried/missing CTA; high attention ratio (full nav + link farm on a campaign lander); CTA lost in accent-color noise; decorative imagery louder than the message; filler sections; ghost/low-contrast primary button (also a 1.4.11 a11y risk); everything crammed above the fold; strongest argument buried mid-page. [HIGH/MEDIUM]

## Phase 4: Contrarian
- **"The fold is dead" / CTA-below-fold can win:** documented A/B cases where a CTA well below the fold beat the above-fold control on long, desire-building pages — because high-intent visitors scroll. Resolution: rule is not "CTA above fold" but "reachable without hunting, present in first viewport AND repeated at decision points." [HIGH] — unbounce CTA-placement case study; disruptiveadvertising
- **Conversion emphasis vs deception:** aggressive hierarchy (fake urgency/scarcity, disguised secondary actions) crosses into dark patterns — dominance must come from honest hierarchy. (Links to ethics guide.) [HIGH]
- **1:1 is the campaign-lander ideal**, not a universal — homepages/content pages legitimately serve multiple intents; apply proportionally (one clearly dominant action per viewport). [HIGH]
