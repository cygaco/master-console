# The Playbook

A living collection of **plays** — hard-won operating principles for taking products from idea to PMF (the [product lifecycle](product-lifecycle.md)). Each play is a reusable judgment: a named belief with the reasoning and an example. The Director of Product and the Quality Lead consult this; grow it over time via `/playbook:add`.

> **This is a blank-slate playbook.** It contains no plays yet. Add plays as they're earned, via `/playbook:add`. Keep each play short, opinionated, and example-anchored. Sections are extensible — add a new one only when no existing section fits.
